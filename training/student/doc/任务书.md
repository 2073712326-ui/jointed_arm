# 双关节机械臂中期项目

## 1. 项目内容

> basic
> 
使用两个 M3508 电机驱动串联机械臂，让末端发光点沿预设轨迹运动。

机械结构按“基座 → 第一关节 → 第二关节 → 发光点”连接。

## 2. 工程说明

已经提供底层驱动、CAN 通信、遥控接收、PID、反馈滤波和任务调度。

仅供参考，**_非常鼓励完全不同的代码设计_**

| 文件 | 需要完成的内容 |
|---|---|
| `arm.cpp` | 反馈读取、标定、使能与失能、限位、参考写入、手动积分、轨迹执行与取消、电机目标输出 |
| `arm_kinematics.cpp` | 正解、逆解、累计角度处理、整段直线可达性判断 |
| `arm_trajectory.cpp` | 五次位置插值、直线采样、运行和结束状态 |
| `control.cpp` | 遥控校准、双关节手动控制、正方形动作 |
| `motor_monitor.cpp` | 电机参数、PID 调试和进阶优化 |

类、成员变量和函数接口已经给出，主要功能的函数体留空。：

- 主控为 STM32F407。CAN1 上 J1 的电机 ID 为 1，J0 的电机 ID 为 2。
- 两杆同向沿 +X 伸直时，两个关节角均为零。逆时针为正，J1 是第二杆相对第一杆的角度。
- 因机械结构，J0 的传动方向修正为 `ratio=-1`，J1 为 `ratio=1`。电机层统一换算反馈和输出方向。
- Arm 内部位置用 m、角度用 rad、时间用 s；Motor 接口的角度和速度用 deg、deg/s。
- 控制周期为 1 ms。关节角±10圈。

## 3. 基础功能

### 3.1 标定和手动控制

3508没有绝对值编码器，所以需要每次上电标定角度。

在失能状态下，将两杆同向沿 +X 摆直，标定两个关节的零点。

### 3.2 正逆运动学

1. 根据两个关节角计算末端坐标。
2. 根据末端坐标求关节角，支持正、负两个肘支。同一段轨迹保持选定肘支，角度衔接时保留累计圈数。
3. 判断整条直线是否可达。

### 3.3 轨迹规划

1. 五次位置插值。
2. 每个控制周期更新一次参考。

### 3.4 画正方形

动作顺序为：

1. 对 A 点求正肘支逆解，用 2 s 移动到预备姿态。
2. 依次走 A→B→C→D→A。
3. 回到 A 后保持目标。
eg.

| 顶点 | X / mm | Y / mm |
|---|---:|---:|
| A | 100 | 100 |
| B | 100 | -100 |
| C | -100 | -100 |
| D | -100 | 100 |

每条边从上一段规划终点开始，参考结束后衔接下一段。整个正方形绕原点顺时针一圈。

官方车遥控器操作如下：

| 挡位 | 操作 |
|---|---|
| 左中右中 | 保持失能，将伸直姿态标定为零位 |
| 左上右上 | 双关节手动控制 |
| 左中右上 | 执行一次预备动作和正方形 |
| 右下 | 停机、取消动作并失能 |
| 其余挡位 | 保持当前位置目标 |

## 4. 评价标准

| 阶段 | 检查内容                                                        |
|---|-----------------------------------------------------------------|
| 标定与手动控制 | 零位正确、使能时目标连续、摇杆方向正确、回中保持目标            |
| 运动学 | 正逆解结果一致、能够识别到运动学不可行的轨迹                    |
| 轨迹规划 | 插值起终点和用时正确       |
| 完整动作 | 四边顺序正确、参考连续、只触发一次、J0 净转一圈、结束后保持目标 |

## 5. 可选

1. **PID 细调参**：比较目标与反馈，改善直线、拐角和快速运动时的跟踪。
2. **前馈控制**：接入轨迹规划算出的速度前馈；结合质量、惯量和尺寸信息算出动力学，尝试加速度前馈，比较启用前后的效果。
3. **更多图形**：尝试正圆或其他预设图案，观察圆度和轨迹连续性。
